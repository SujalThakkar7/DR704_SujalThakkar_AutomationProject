\# DR704 Automation Testing Project



\## Project Overview

Automation Testing 11.0 assignment for batch DR704.



This project uses Selenium WebDriver with Java, Maven, TestNG, Cucumber, Page Object Model (POM), Apache POI and ExtentReports.



\## Technologies Used

\- Java

\- Selenium WebDriver

\- Maven

\- TestNG

\- Cucumber

\- Apache POI

\- ExtentReports



\## Project Structure

\- `src/test/java` – Java test classes, page classes, utilities and step definitions

\- `src/test/resources/features` – Cucumber feature files

\- `src/test/resources/testdata` – Excel test data

\- `smoke.xml` – Smoke test suite

\- `regression.xml` – Regression test suite

\- `pom.xml` – Maven dependencies and configuration

\- `evidence/` – Test reports and screenshots



\## How to Run

Smoke suite:

`mvn clean test -Psmoke`



Regression suite:

`mvn clean test -Pregression`
